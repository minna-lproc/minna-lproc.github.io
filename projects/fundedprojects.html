Project iWag: A Mobile-Web Bidirectional Neural Machine Translation System for Filipino and Cebuano

About the Project:

This project presents the development of a Mobile-Web Bidirectional Neural Machine Translation System for Filipino and Cebuano, employing a hybrid approach to enhance translation accuracy and efficiency. The project aims to address the linguistic challenges between these two languages by focusing on four key objectives.

  1. collect translated bidirectional parallel corpus of documents, and domain knowledge documents for Filipino and Cebuano
  2. employ pre-processing techniques to be used in preparing the data for translation
  3. apply hybrid approach in developing the machine translation system, and
  4. evaluate and analyze the translation result.
